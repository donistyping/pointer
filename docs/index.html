Pointer

A tiny menu-bar utility that fixes what macOS won't: flip your mouse wheel without touching the trackpad, turn notchy scrolling into a glide, and put the extra buttons to work.

Same wheel, different physics

Both panels below are fed the same eight wheel clicks. The only difference is what a click does — which is exactly what Pointer changes. (Animation paused for reduced motion: the left panel jumps a fixed chunk per click; the right one glides the same distance and settles.)

Three fixes, nothing else

Reverse the wheel

macOS ties the mouse and trackpad to one "natural scrolling" switch. Pointer flips only the wheel, so the trackpad keeps behaving like a trackpad.

Smooth the notches

Each click of the wheel becomes an eased glide instead of a jump — the same easing you see in the demo above, tuned with two sliders.

Remap the buttons

Middle-click, the side buttons, even the wheel-click: send them to Mission Control, Spaces, Back/Forward, or Launchpad. A Detect button binds whatever your mouse reports.

It asks for one permission — here's the honest why

Reshaping scroll and click events is precisely the thing macOS gates behind Accessibility access, so Pointer can't work without it. Software that can watch your input deserves suspicion, so the whole case for trust is verifiable:

  • Zero network requests. Pointer has no networking code at all — no telemetry, no update phone-home, nothing to send your input to.
  • Small enough to actually read. The entire app is a few hundred lines of Swift, MIT-licensed on GitHub. The download is 488 KB.
  • Easy to walk away from. Quit it from the menu bar and it's inert. Uninstall is the app, one launch agent, and one settings file — documented in the README.

First open, two honest steps

Pointer isn't notarized by Apple — that's a $99/year developer subscription this free app doesn't have. macOS will make you vouch for it once:

  1. Open it deliberately. On macOS 13–14: right-click Pointer.app and choose Open. On macOS 15 and later: open System Settings → Privacy & Security and click Open Anyway.
  2. Grant Accessibility when it asks. Pointer activates on its own within a couple of seconds — no relaunch, and the menu-bar mouse turns "active."

Or build it yourself

Building from source skips the Gatekeeper step entirely — locally built apps are never quarantined. All it needs is Apple's Command Line Tools.

# compiles universal, installs to /Applications, starts at login
git clone https://github.com/donistyping/pointer
cd pointer && ./build.sh install
